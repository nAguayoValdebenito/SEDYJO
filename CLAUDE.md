# Comercial Sedyjo — frontend

Tienda online (Next.js 16 + TypeScript + Tailwind v4). Solo frontend; el backend lo hace otra persona.

- Convenciones y arquitectura: skill `sedyjo-frontend`. Para agregar pantallas: skill `sedyjo-nueva-seccion`.
- Next.js 16 difiere de versiones anteriores: leer `AGENTS.md` y la guía en `node_modules/next/dist/docs/` antes de programar.
- **No hacer commits, push ni cambios en GitHub (repo SEDYJO) salvo que el usuario lo pida expresamente.**
- Verificación: `npx tsc --noEmit && npx eslint && npm test && npm run build`.
